# Bundled typography

Space Grotesk variable (500 and 700 used) and Space Mono Regular/Bold are
embedded via `ui::Assets`, loaded once by `ui::init`, and used without relying
on desktop font installation. Source: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
and https://github.com/google/fonts/tree/main/ofl/spacemono (retrieved 2026-10-15).
Both families use the included SIL Open Font Licenses.
