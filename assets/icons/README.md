# Tabler icons

Source: https://github.com/tabler/tabler-icons (retrieved 2026-10-15; search icons added 2026-10-24).
MIT license included. Outline icons use a 24px grid and are adapted only by
changing stroke-width from 2 to the design's 2.5. Play and pause use the
upstream filled variants. GPUI requires an explicit SVG tint; the shared
icon helper supplies ink by default and icon buttons override it with the semantic foreground color.

Google and Last.fm brand marks are bundled separately as provider identity assets;
they render in their brand colors through image elements, not monochrome SVG tinting.

The playlist editor's `world`, `link`, and `lock` outlines reproduce the approved
mock's simple geometric icons on the same 24px grid and 2.5px stroke.
