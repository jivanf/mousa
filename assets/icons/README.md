# Tabler icons

Source: https://github.com/tabler/tabler-icons (retrieved 2026-10-15).
MIT license included. Outline icons use a 24px grid and are adapted only by
changing stroke-width from 2 to the design's 2.5. Play and pause use the
upstream filled variants. GPUI requires an explicit SVG tint; the shared
icon button supplies the semantic foreground color.
