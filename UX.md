# Buttons

## Tooltips

- Use button tooltips selectively, only when they clarify an otherwise ambiguous
  action.
- Do not add tooltips merely because a button uses an icon. Universally understood
  controls such as Play, Pause, and the search input's clear (×) button need none.
- Avoid tooltips that simply repeat a visible label or an obvious action.
- Keep useful explanations for ambiguous actions or destinations, error details,
  and truncated content. Preserve accessibility labels independently of tooltips.
